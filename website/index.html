The editor that doesn’t get in your way

sie stands for siMPLE eDITOR. A small, modeless terminal editor in Go: open a file, type, save. One static binary for Linux, macOS and Windows, with no C dependencies.

Everything in reach, nothing to learn first

Three ways to run any command: a shortcut, the menu bar, or the prompt. The prompt always shows the shortcut, so you pick them up as you go.

Modeless

No modes, no leader keys. Arrows, Ctrl+S, Ctrl+Z and the mouse work the way you expect.

Command prompt

Fuzzy-find any command: goto 42, find foo, trim sel. Your recent commands come first.

Multiple cursors

Alt+click adds a cursor. Alt+drag or column mode selects a rectangle. Undo restores all of them.

Mouse that helps

Double-click selects a word, triple-click a line, and dragging extends by word or line.

Validation

Checks JSON, YAML, TOML and XML, jumps to the first error, and asks before saving a broken file.

Syntax highlighting

Every language chroma knows, colored in the background so typing never waits.

Careful with your files

LF and CRLF kept, BOM kept, invalid UTF-8 never corrupted, saves are atomic. Cursor moves by grapheme.

Visual helpers

Optional click ripple and an indent guide that flashes how a line lines up. Great for Python and YAML.

One binary

Pure Go, CGO_ENABLED=0, six targets: Linux, macOS and Windows on amd64 and arm64.

Install

Latest release: __VERSION__.

Homebrew macOS, Linux

brew install --cask avero-it/tap/sie

Scoop Windows

scoop bucket add avero-it https://github.com/avero-it/scoop-bucket
scoop install sie

apt Debian, Ubuntu · amd64, arm64

sudo curl -fsSL https://avero-it.github.io/sie/sie.gpg -o /usr/share/keyrings/sie.gpg
echo "deb [signed-by=/usr/share/keyrings/sie.gpg] https://avero-it.github.io/sie stable main" | sudo tee /etc/apt/sources.list.d/sie.list
sudo apt update && sudo apt install sie

The repository is signed and updated with every release; after that, sudo apt upgrade keeps sie current.

deb, rpm, apk Linux packages

Download from the releases page, then:

sudo apt install ./sie_<version>_linux_amd64.deb
sudo dnf install ./sie_<version>_linux_amd64.rpm
sudo apk add --allow-untrusted ./sie_<version>_linux_amd64.apk

Go Go installed

go install github.com/avero-it/sie/cmd/sie@latest

Binaries

Pick the archive for your platform on the releases page, unpack it and put sie (sie.exe on Windows) on your PATH. SHA-256 sums are in checksums.txt. On macOS, allow a browser-downloaded binary once:

xattr -d com.apple.quarantine ./sie

Move by word with Alt+←/→ or Ctrl+←/→, by jump_lines lines with Alt+↑/↓, to the line ends with Home/End and to the file ends with Ctrl+Home/End. Add a cursor with Alt+click.

Configuration

sie reads /etc/sie/config.yaml and then ~/.sie/config.yaml; keys in your file win. SIE_* environment variables override both. sie config prints the effective settings.

tab_width: 4            # 1–16
show_invisibles: false  # mark spaces (␣) and tabs (»)
show_empty_cells: true  # mark cells holding no character (·)
click_ripple: false     # a wave animation on every click in the text
indent_guide: false     # briefly show a vertical guide when a line's indent moves
line_ending: lf         # for new files: lf or crlf
jump_lines: 5           # lines moved by Alt+↑/↓ (1–100)
syntax_highlighting: true
syntax_max_size: 2MB    # larger files are not colored
validate_on_save: true  # check JSON/YAML/TOML/XML before saving

Terminal notes

  • macOS: Ctrl+Alt and Alt+click need Option to act as Meta (Terminal.app: Use Option as Meta key; iTerm2: Left Option key = Esc+).
  • Windows: Ctrl+Alt is AltGr on many layouts; sie types the character unless that exact combination is bound.
  • Clipboard: copy goes through the terminal (OSC 52, also over SSH) and the native clipboard.
